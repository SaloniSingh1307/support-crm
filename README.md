# Support CRM

A full-stack customer support ticket management system.

## Tech Stack

Frontend:
- React.js
- Vite
- CSS

Backend:
- FastAPI
- Python
- SQLite

Deployment:
- Frontend: Vercel
- Backend: Render

## Features

- Create support tickets
- View tickets
- Update ticket status
- Search tickets
- REST API integration
